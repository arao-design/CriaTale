## Objetivo do Software
O **CriaTale** é uma aplicação desktop voltada para auxiliar na criação, geração e organização de histórias fictícias e personagens, oferecendo uma interface estruturada, navegação intuitiva e persistência de dados em banco relacional.

## Funcionalidades do Sistema (Requisitos)
* **Autenticação / Acesso:** Tela inicial para acesso ao sistema e cadastro rápido de usuário.
* **Visão Geral (Dashboard):** Exibição de indicadores de histórias criadas, em andamento e concluídas, além de atalho para criação de novas histórias.
* **Criação e Geração de Histórias:** Definição de título, gênero, público-alvo, extensão e ideia/enredo, com apoio de sugestões rápidas e salvamento no banco de dados.
* **Minhas Histórias:** Consulta das histórias persistidas no banco em tabela e visualização do conteúdo completo da história selecionada.
* **Gerenciamento de Personagens:** Cadastro e listagem de personagens com nome, papel e descrição.
* **Configurações e Acessibilidade:** Opções de preferências do sistema, incluindo alternativa de alto contraste.
